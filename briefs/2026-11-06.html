OpenAI ships GPT-6 Cyber, rated "Critical" for cybersecurity under its own framework

The model already found 81 previously-unknown high-severity Firefox bugs and powered a Linux kernel sweep that cost $1.2M in API credits, while Anthropic open-sourced a way to cryptographically prove which model answered you, and used Claude to map the first 3D structure of a bacterial vault particle.

4 stories · 4 sources · 5 min read · listen 8:00

Top signal

01

OpenAI ships GPT-6 Cyber, rated "Critical" for cybersecurity

Per Reuters, OpenAI released GPT-6 Cyber on Thursday to a small group of vetted customers, rating it "Critical" for cybersecurity under its own safety framework — up from "High" for the prior GPT-5.6 Cyber. The model is built to find and exploit security flaws so defenders can fix them first, and access is expanding to all approved Daybreak Red customers over the coming weeks; OpenAI is also opening the older GPT-5.6 Cyber to all Daybreak Red customers starting now. OpenAI's own account says the model powered the Linux kernel research it announced the day before and that security teams at Mozilla, Palo Alto Networks and Cisco are already using it. Per OpenAI's technical report (via Unite.AI's write-up), that Linux run analyzed 2,308 candidate findings, reproduced 1,724 vulnerabilities and generated 948 distinct local-privilege-escalation exploits, at a cost of $1,213,430 in API credits, with human researchers reviewing everything before disclosure. Mozilla's own Firefox 159 advisory separately credits OpenAI's security team with 81 previously-unknown high-severity vulnerabilities and 30 reclassified as more severe than first reported.

Signal: this is the follow-through on Tuesday's Cathedral security sprint — not more planning, but a shipped model with real numbers: a Linux kernel sweep that reproduced 1,724 vulnerabilities and produced 948 working exploits, and a Firefox 159 advisory crediting OpenAI researchers by name for 81 previously-unknown high-severity bugs.

02

Anthropic open-sources FlashProve, a way to cryptographically prove which model answered

Per Anthropic's own research post, FlashProve is an open-source prototype for "provable inference": a cryptographic proof that a specific reply came from a specific AI model, without exposing the model's weights. On a single H100 GPU it proves a 400B-parameter mixture-of-experts model (Llama 4 Maverick) at roughly 110 tokens/second, with each proof only about 19 MB and verifiable in seconds — Anthropic says the best prior open method, VerInf, took over 14 hours to prove 1,000 tokens. Anthropic's Frontier Red Team built it with collaborators at EPFL, MIT and StarkWare, and frames the use case as making it harder to hijack a chat session or spoof which model actually served a response, plus letting safety evaluators confirm they're testing the model that's really in production.

Signal: a genuinely new primitive, not an incremental benchmark — FlashProve proves a 400B-parameter model's output 70-95x faster than the fastest prior open method (VerInf), which makes "verify this response really came from this exact model" practical for the first time rather than a research curiosity.

Source: anthropic.com/research/provable-inference

03

Anthropic uses Claude to map the first 3D structure of a bacterial vault particle

Per Anthropic's own post, its life sciences team worked with Claude to solve the first 3D structure of a vault particle — a large, barrel-shaped protein shell whose function has been unknown since its discovery by Leonard Rome and Nancy Kedersha in 1986 — found this time in a bacteriophage-infected E. coli system rather than the animal and plant cells where vaults were previously known. Anthropic says the bacterial version has 96 protein chains versus 78 in a human vault and an roughly 25% larger internal cavity, and frames the four-month project explicitly as a demonstration of both the potential and the limits of using AI to accelerate real science.

Signal: a concrete, verifiable science result rather than a capability claim — Anthropic's biology team submitted an actual structure (3.2 Å resolution, bioRxiv-bound) that extends a 1986 open question in cell biology to bacteria and the viruses that infect them, with Claude doing the directed computational work, not the science itself.

Source: anthropic.com/research/provable-inference

04

Mistral runs a 133-agent swarm to triage and patch a Django vulnerability

Per Mistral's own account and CryptoBriefing's write-up, Mistral set 133 specialized agents loose on a recent Django CVE: some mapped the codebase, others hunted for the flaw, simulated attacks, and reproduced the bug, before a dedicated patching agent nicknamed "Le Chonk" fixed it — shown at 90x speed, end to end. The timing was pointed: Django published its fix on November 3, and Mistral's demo ran the next day. Mistral is pitching the open-weight Large 4 as a self-hostable alternative for security teams wary of sending proprietary code to a closed API.

Signal: a slick demo more than a verified benchmark win — outside commentary notes Mistral tested this on an already-known, already-patched Django CVE (not a zero-day discovery), and that Mistral's own published cybersecurity index still ranks Large 4 behind DeepSeek V4.1 Flash and Xiaomi's MiMo.

Bottom line

A quieter few days for new model launches but a telling one on security: OpenAI moved from announcing a security sprint to actually shipping a "Critical"-rated cyber model with real vulnerability counts, Anthropic open-sourced cryptographic proof-of-inference, and Mistral ran a flashy (if not fully independently verified) agent-swarm security demo — three labs converging on "AI defending against AI" as the live story, not a future one.
