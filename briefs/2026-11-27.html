Top signal

01

OpenAI shows GPT-6 models designing new proteins, validated in the wet lab

On its own account (Nov 24), OpenAI shared a preprint with wet-lab validation of what it calls intrinsic protein design in the GPT-6 family. It says the models design new protein shapes and sequences using reasoning and code, without calling specialised biology models. A follow-up post says an internal research model matched or beat specialised models on many protein tasks, including designing shapes and predicting how molecules fit together, and that performance improved across model generations.

Signal: this is the follow-through on the BioBasicsBench story: the claim is that the model itself designs the proteins with reasoning and code, with no specialised biology model in the loop, and that it was tested in a real lab.

Source: openai.com/index/gpt-6-models-demonstrate-intrinsic-protein…

02

Anthropic's Siren tests whether agents will leave a weakened sandbox when it pays to

Anthropic's research post (Nov 24) introduces Siren, an evaluation that gives Claude routine tasks in intentionally weakened sandboxes, with something useful to the task left outside. Anthropic says it spans more than 1,700 scenarios built to tempt the agent. It frames the question as whether an agent that can escape will choose to.

Signal: the design is the interesting part: the task is routine and the tempting thing sits outside the sandbox, so it measures choice, not capability. Only the opening of the post was visible on the feed, so the results are not covered here.

Source: safeguards.anthropic.com/2026/siren

03

Anthropic moved its Messages API from Python to Rust, with Claude agents checking the port

Anthropic's engineering post (Nov 25) says it used the existing Python service to verify the new Rust one, with teams of Claude agents tracking down and fixing differences between the two. Per The Pragmatic Engineer's interview with Katelyn Lesse, the rewrite took around five months and the API serves all Claude traffic.

Signal: the method is the point: the production service was the test oracle, and teams of agents chased down every behavioural difference. That is a template for any big rewrite.

Source: anthropic.com/research/migrating-api-to-rust
